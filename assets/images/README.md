# Imagenes del sitio

Copia las imagenes en esta carpeta usando estos nombres exactos. El sitio es estatico: no tiene un formulario que suba archivos al servidor; agregar una imagen significa copiarla aqui con el nombre esperado.

- `logo-viajes-piedrahita.png`: logo del emprendimiento, usado en la navegacion.
- `renault-clio.jpg`: fotografia del Renault Clio en la portada.
- `cali.jpg`: fotografia para la tarjeta de Cali.
- `jamundi.jpg`: fotografia para la tarjeta de Jamundi.
- `palmira.jpg`: fotografia para la tarjeta de Palmira.
- `el-cerrito.jpg`: fotografia para la tarjeta de El Cerrito.
- `poblado-campestre.jpg`: fotografia para la tarjeta de Poblado Campestre.
- `villagorgona.jpg`: fotografia para la tarjeta de Villagorgona.
- `ruta-valle.jpg`: fotografia opcional compartida en las paginas informativas y de contacto.

Puedes usar JPG, PNG o WebP, pero si eliges otra extension deberas actualizar el `src` correspondiente en el HTML. Las fotos de localidades se recortan automaticamente en circulo.
